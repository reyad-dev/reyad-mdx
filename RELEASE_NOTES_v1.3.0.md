# ReyadMDX 1.3.0 — Version and update checks

- See the current version beside the app name and in Settings on every platform.
- Windows and Android check for stable GitHub releases at startup. Use **Check for updates** to retry whenever you want.
- A newer release displays an update notice. **Download update** opens the official installer, portable EXE or APK for your current app.
- Save your work and open the downloaded file to complete installation. Android retains the existing signing identity; portable users run the new executable.
- Web/standalone HTML has manual checks and opens the latest published web copy in a new tab. Download the attached HTML for a fresh offline copy.
- Offline reading and editing continue to work. Failed checks can be retried; unfinished platform uploads are clearly identified.

**First upgrade:** older releases do not contain the update checker. Download 1.3.0 manually once; it will detect subsequent releases.

Shared reader/editor changes are included in Windows, Android and the public HTML build. Native system features belong to their platform. Installed applications and saved HTML files need an update to receive new code.
